Executable cases: `packages/subscriptions/src/__tests__/plan-versions.test.ts` (SQLite, including the shared scenario) and `plan-versions.optional.test.ts` (the same scenario plus column types on PostgreSQL), sharing `__tests__/helpers/plan-version-scenario.ts`.

Atomicity: the plan row is written before its version without a package-owned transaction (a wrapping transaction would serialize the #3829 coordinated natural-key race on SQLite). A failed publish rejects the save and the next save publishes the missing version; callers needing atomicity wrap the save in `plan.withTransaction()`.

Out of scope: commerce period-close still prices flat-plan periods from the live plan row; billing from the pinned version is follow-up #4146.
