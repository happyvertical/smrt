## Overview

The Asset Library keeps files and media in one place. Organize assets into folders, classify them by type and status, and keep a clear description for people who need to find them later.

## Tasks

### Add an asset

1. Give the asset a recognizable {field:Asset.name}.
2. Add a {field:Asset.description} that explains how the file can be used.
3. Select its {field:Asset.folderId}, {field:Asset.typeSlug}, and {field:Asset.statusSlug}.
4. Confirm the {field:Asset.mimeType} matches the file you intend to manage.

### Organize folders

1. Create a folder with a descriptive {field:Folder.name}.
2. Use the {field:Folder.description} to explain the folder's purpose.
