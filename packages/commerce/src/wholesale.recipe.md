## Overview

Wholesale orders are bulk orders from trade customers. They work like sales
orders, with a list of line items, but are kept in their own list so trade and
retail sales stay apart.

## Tasks

### Take a wholesale order

1. Create a new wholesale order.
2. Pick the **{field:customerId}** placing the order.
3. Add the line items and check the **{field:totalAmount}**.
4. Set the **{field:dueDate}** for payment and save.

### Track it

1. Update **{field:status}** as the order moves from draft to completed.
2. Use **{field:reference}** for the buyer's own order number.
