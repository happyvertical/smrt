## Overview

Taxonomy is a shared list of tags you can use to organise anything in your app.
Tags can sit inside other tags, so a broad tag such as "Events" can hold
narrower ones such as "Concerts" and "Workshops". A tag can also have
alternative names, including translations, so people find it by whichever word
they know.

## Tasks

### Add a tag

1. Choose the **New** button above the list of tags.
2. Give the tag a **{field:name}** people will recognise.
3. Add a **{field:description}** that says what belongs under it.
4. Save. The tag is now ready to use.

### Put a tag inside another tag

1. Open the tag from the list and choose Edit.
2. Pick the **{field:parentId}**, the broader tag it belongs under.
3. Leave it empty to make the tag a top-level tag.
4. Save. Moving a tag moves everything under it too.

### Add another name for a tag

1. Open the list of alternative names and choose **New**.
2. Pick the **{field:tagSlug}** the new name belongs to.
3. Type the **{field:alias}**, for example a common nickname or a translation.
4. Set the **{field:language}** if the name is in a specific language.
5. Save. The alternative name is now on file for that tag.

### Keep the list tidy

Keep one tag for each idea. If two tags mean the same thing, record the second
as an alternative name instead of keeping both.
