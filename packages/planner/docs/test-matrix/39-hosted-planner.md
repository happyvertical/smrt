The host session test covers pure refresh and reconnect paths. `pnpm test:mcp-browser` builds the self-contained MCP resource, mounts it in Chrome, exercises tool-driven refresh, checks that a transport retry reuses its UUID and revision, verifies a conflicting edit keeps its draft, refuses a persisted browser theme as a plan edit, sends a chosen theme preset as a Kitchen command, and recovers from a malformed first payload. `pnpm test:live-preview-browser` runs the Vite app against a loopback stub and checks that a lost preview response locks the app, preserves the draft and retries the same batch id.
