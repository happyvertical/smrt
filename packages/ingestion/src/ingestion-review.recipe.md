## Overview

Ingestion review lets an authorized person inspect the evidence behind a
proposed action before it can affect another record. A decision is tied to the
specific material and proposal that the reviewer saw.

## Tasks

### Review a proposed action

1. Open an inbox item that has a proposed action.
2. Read the evidence and the proposed result in the authenticated review host.
3. Approve, change, reject, or defer the proposal according to the current
   application policy.

### Return to an item after it changes

1. Refresh the review when the host indicates that the material or proposal has
   changed.
2. Review the current proposal before making a decision.
3. Leave a proposal deferred when its evidence or destination is still
   uncertain.

## Preview status

This recipe describes a preview workflow. The published evaluation did not meet
quality gates and did not establish safety, so automation remains disabled. It
does not create a generic editing surface or enable automatic execution. A host
rechecks the reviewer, scope, and current proposal before it accepts a decision.
