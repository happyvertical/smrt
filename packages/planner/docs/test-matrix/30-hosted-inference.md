Credential handling and generated fallback routing are high risk because a
single missed browser surface can retain a key and a single root-relative
reference can break every deep link. The final review therefore requires
independent security-boundary and packaged-routing reviewers on the committed
revision. Live provider success, CDN deployment, registry publication, and
hosted ChatGPT access are outside pre-merge evidence.
